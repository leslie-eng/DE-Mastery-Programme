what could go wrong if you retried a request that creates something such as a payment and why this is safe for a read-only call
-> if a payment is retried, the client is billed based on the number of attempts the request is made which would lead to a complaint thus time wasted trying to refund payment. 

Why this is safe for a read-only call:
This eliminates the need to make any changes to the data that is written to the database thus altering the raw data.
